Admin Console — Navigation Redesign

An ops / work-queue reorganization of the admin console for desktop + mobile. Today's 6 noun-domain groups (Home / Queues / Directory / Money / Insights / Manage) are re-cut along the verb an admin actually performs: act on what's pending → look things up → tune the platform. One nav source of truth — desktop expands, mobile flattens.
