Dropping refunds the base value only. The premium delta was never in the package, so it can’t come out.
Why no words. Couples learn in three seconds: no box = it’s in; a box = I can drop it; circles = I must pick. Labels would just add noise to a screen that’s already doing arithmetic.

Vendors have no package builder at all today — packages exist only as a database seed. This lives inside the existing shop manager, in the same repeater grammar as the add-ons editor. No new page.
