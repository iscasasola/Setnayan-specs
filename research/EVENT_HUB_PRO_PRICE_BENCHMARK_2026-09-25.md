# Event Hub Pro — Price Benchmark vs. the Real-World Market (2026-09-25)

**Question asked by the owner:** *"Check the reasonable price for all of these features? Check online the
nearest combination that would cost a user to do all of these?"*

**Method.** Every figure below is either (a) a public, current (2025–2026) price with a cited URL, or
(b) explicitly marked **ESTIMATE** with the reasoning shown. No number is invented silently. FX rate used
throughout: **1 USD ≈ ₱62.60–62.94** (BSP reference rate + Wise, measured 2026-09-24/25 —
[BSP via PesoHub](https://pesohub.ph/rates/exchange-rates/usd-to-php-today/),
[Wise history](https://wise.com/us/currency-converter/usd-to-php-rate/history)). Rounded to **₱62.7 = $1** for
all conversions below; re-measure before quoting this file as current — it will have drifted.

All comparisons are sized to a **100-guest wedding**, the size most vendor price sheets themselves assume.

## 0. What Event Hub Pro actually is (per owner rulings 2026-09-22/25)

One-time unlock, per event, valid ~10 years:

1. **Themes/styling** — 9 premium themes (each with its own looping background video + fonts), adaptive
   theme (colours follow the couple's own video), custom fonts/colours (plain or ombré), animations and
   scene transitions.
2. **The reveal** — every animated opening (envelope/doors/veil) plus the Save-the-Date film opening.
3. **Animated monogram logo.**
4. **Media** — the couple's own photo/video uploads (100MB, compressed), media backgrounds, background music.
5. **Galleries** — gallery additions.
6. **Scenes** — 4 auto-transitioning stages: Save the Date → Invitation → On the Day → Post Event.
7. **Love Story** — >5 moments with photos and video.
8. **Post Event** — auto-built story/editorial page: galleries, film, guest wishes, reader-aware galleries.
9. **Prints, matching the website 100%, print-ready with bleed/crop marks** — invitation set, per-guest
   passes/tickets with QR, event card, A3 welcome poster, place cards, table signs, guest registry, seat plan.

Free for everyone (context only): Classic theme page, word-edit, plain colour, hide/reorder, 5 word-only
Love Story moments, guest photos, auto Post Event, RSVP with per-guest QR + check-in, every print in Classic.

**Current prices:** ₱3,500 regular · ₱2,100 if bought during onboarding.

## D. Recommendation

**Recommended band for Event Hub Pro: ₱2,999–₱4,999**, keeping the onboarding discount somewhere in
**₱1,999–₱2,999**.

**Reasoning:**

1. **Every global "wedding website" product gives the site away free.** The website itself (Item 1) is not
   where the market charges money — Zola, The Knot, Joy, and Riley & Grey's free tier all prove that. Event
   Hub Pro's website layer alone would be overpriced at ₱3,500 if that were the only comparison — but that
   is not what it is selling.
2. **The market charges for exactly the three things Event Hub Pro also charges for: premium animated
   design assets (reveal, animated monogram, video-background themes) and the print suite.** Those are
   priced everywhere as separate, stacked purchases — Paperless Post ($96/send), Ink Scribbler bespoke
   (₱24,000), Fel & Ink (₱20,000+), Feliz Studio (₱10,000+print), Fiverr/Upwork animation ($20–$100+ per
   asset). **The cheapest realistic assembly of the same feature list, at 100 guests, is ≈₱20,150; a
   designer-led mid-range assembly is ≈₱77,345** (Section C).
3. **₱3,500 (regular) is roughly 17–20% of the cheapest DIY stack and ~4–5% of the mid-range designer
   stack** for a bundle that, unlike either stack, guarantees the print suite matches the website 100%
   automatically (no separate designer round-trips, no manual re-application of the monogram file to a
   second vendor's templates — the exact mismatch problem Section B found is unsolved anywhere in the PH
   market today).
4. **There is real headroom to raise the price without losing the value story.** Testing toward the top of
   the band (₱4,499–₱4,999 regular / ₱2,999 onboarding) would still undercut the cheapest DIY stack by
   roughly 4x and the designer-led stack by roughly 15x, while meaningfully improving unit economics on a
   feature set that includes real per-couple cost (100MB media storage, compressed video, print-ready file
   generation).
5. **Philippine purchasing-context caveat:** ₱3,500–₱4,999 is not a trivial add-on for a PH wedding budget
   — it sits close to what a couple would otherwise spend on Feliz Studio's cheapest 20-set invitation
   bundle (₱3,500) or one InviteCount Signature purchase (₱3,380) *alone*, before any printing. Any move to
   the top of the band should be framed and tested carefully, ideally A/B'd at checkout, rather than moved
   in one step — this is a pricing lever, not a locked decision, and should get explicit owner sign-off
   before shipping, per this repo's Cowork/DECISION_LOG convention.

**Where the data is thin (do not treat these as settled):**
- PH-specific animated-monogram sellers (Facebook/Instagram) — none found with a published price; the
  Fiverr/Upwork/Envato/Canva figures used are the best available proxy, not a PH-market price.
- Per-guest QR personalization printing cost in the PH market — no vendor itemizes this separately from
  flat ticket printing; the ₱5–₱15/pc estimate above is a placeholder, not a measurement.
- Guest-registry-sign and seat-plan-design PH pricing — no local vendor found with a published price;
  international Etsy figures were used as estimates only.
- No PH vendor was found who sells a matched website + print + monogram as a single coordinated product —
  this is stated as a finding (Section B), not filled with a guess.
