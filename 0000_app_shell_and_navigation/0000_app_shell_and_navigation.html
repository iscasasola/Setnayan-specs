Iteration 0000 · What ships

Login. Pick your event. Get to work.

Iteration 0000 is the foundation. It's the layer that lets the couple actually open and use Setnayan. Without it, every other iteration's panel exists as an orphan URL. With it, everything connects through one consistent shell.

Auto-jump rule (after sign-in)

0 events
Welcome screen with "+ Create your first event"
1 active event
Skip the picker. Take the couple straight into that event's Guest List tab.
2 or more active events
Show the event picker. Couple picks which event to enter.

"Active" means an event the couple hasn't archived. Archived events are still accessible from the picker but don't count toward auto-jump.

The four bottom-nav tabs

👥
Guest List
Guests (0001), Invitation Site (0002 + 0004), Seating Chart (0008)
💼
Vendors
Vendor List (0006), Budget (0007)
📅
Schedule
Unified calendar — vendor meetings (0006) + payment deadlines (0007) + event-day timeline (0004) + countdown
✨
In-App Services
Wallet (0003), Mood Board (0010), LED (0005), Photo Delivery (0009), Panood (0011), Papic (0012)

URL pattern

setnayan.com/login
Sign-in
setnayan.com/dashboard
Top-level (event picker if 2+ events; auto-redirect if exactly 1)
setnayan.com/dashboard/profile
Profile + Settings
setnayan.com/dashboard/[event-id]
Event home — auto-jumps to Guest List tab
setnayan.com/dashboard/[event-id]/[section]
Any tab's sub-page (guests / vendors / budget / schedule / services / ...)
setnayan.com/[event-slug]?invite=...
Guest-facing personal invitation site (existing, owned by 0002)

Schema additions

Two columns added to the existing events table from 0001. No new tables.

ALTER TABLE events ADD COLUMN is_primary BOOLEAN NOT NULL DEFAULT FALSE;
ALTER TABLE events ADD COLUMN archived  BOOLEAN NOT NULL DEFAULT FALSE;

CREATE UNIQUE INDEX events_one_primary_per_couple
  ON events (couple_id) WHERE is_primary = TRUE;

What 0001–0012 must do to plug in

Each iteration declares which bottom-nav tab it lives under and uses the event-scoped URL pattern. That's the entire change. The shell handles the rest.
