Refunds & goodwill

V1 doesn't ship the Setnayan Guarantee. Customer disputes go through informal mediation — admin discretion + goodwill credits + case-by-case partial refunds. All cases are logged · the data feeds the V1.5 Guarantee economics.

📋
V1 mediation rules (informal): < ₱5K refund — admin discretion. ₱5K–₱20K — admin + reason in audit log. > ₱20K — two-admin approval. No contractual guarantee; this is goodwill customer service.
