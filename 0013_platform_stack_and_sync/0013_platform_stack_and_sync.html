Iteration 0013 · The foundation

Build this first. Everything else depends on it.

Iteration 0013 is the platform infrastructure that all 12 V1 feature iterations sit on top of. Despite being numbered 0013, it must ship as Sprint 0 — before iteration 0000 begins. The numbering is for ledger organization; the build order is "this comes first."

The stack

GitHub (source of truth for code) │ ├──► Vercel (auto-deploys main branch → web frontend) │ Next.js + React, Supabase JS SDK in browser │ ├──► Supabase (auto-applies migrations from /supabase/migrations/) │ Postgres + Auth + Realtime + Storage + Edge Functions │ ├──► Cloudflare R2 (large media — photos, broadcasts, LED renders) │ Free egress + custom domain media.setnayan.com │ └──► YouTube (Setnayan master channel for live broadcast delivery) Sole viewer-delivery surface in V1

Three sections in the spec

Section A — User Setup Checklist. Every account, credential, and configuration that you must obtain. Claude Code can't sign up for accounts on your behalf. Includes Vercel, Supabase, Cloudflare, GitHub, Apple Developer, Google Play, YouTube, PayMongo, Stripe, Anthropic, Resend, Sentry, Suno.

Section B — Claude Code Implementation Guide. Once Section A is complete, Claude Code scaffolds the Next.js project, applies Supabase migrations, sets up RLS policies, builds iOS/Android skeletons, configures the macOS Tauri shell, and wires CI/CD pipelines.

Section C — Integration Tests. 15 verification steps that confirm everything works end-to-end before V1 features start building. Auth, realtime sync, RLS, R2 uploads, YouTube broadcast creation, cross-platform sync, deployment, error tracking.

Production-readiness gate: The platform is ready for iteration 0000 to ship on top of it once all 15 tests in Section C pass. Any failure blocks the V1 launch.

Sprint timeline

Sprint 0a (you, ~1 week elapsed): Section A. Most steps are 15–30 min of clicking; long pole is Apple Developer (1–3 days approval) and PayMongo verification (1–3 business days).

Sprint 0b (Claude Code, ~3–4 days): Section B steps 1–4. Web app skeleton + auth + realtime + RLS.

Sprint 0c (Claude Code, ~1 week): Section B steps 5–7. Native iOS, Android, macOS skeletons. Each authenticates and reads events.

Sprint 0d (Claude Code, ~3 days): Section B steps 8–11. CI/CD + service catalog + R2 helpers + YouTube Edge Function.

Sprint 0e (you + Claude Code, ~2 days): Section C — run all 15 tests, fix anything that fails.

After 0013 ships

Iteration 0000 (App Shell) starts. Then 0001–0012 layer on as feature iterations, each building on the platform 0013 established. Every iteration's data model lives in Supabase, every iteration's UI lives in the Next.js codebase, every iteration's media lives in R2.
