Quiet is where the tree matters most. No wedding to run, no vendor to pay — but a graph that's been quietly filling itself from every binyag, debut and kasal you've been to. This is the only screen in the product that gets better the longer you do nothing.

What is actually new here: one tile and one behaviour. Everything else on this screen is the shipped home reproduced as-is. The Family tile shows the model exactly as it's locked in person_connections — four declarable slots, mutual confirm, derived kin, ritual layer created by ceremonies, friends kept out of the tree. The two postures re-rank the same components by one account-level fact: is anything in motion? The derivation engine behind the gold panel is not built yet — that panel is the specification for it.

The boundary this prototype keeps: the home is the switchboard above every event; the event dashboard is the workspace inside one. Day-of is an event fact, so it stays on the event dashboard where its nine components already ship. The home only ever points at it.
