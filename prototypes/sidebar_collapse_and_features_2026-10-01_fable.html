One motion, four things move together (all on the same 220 ms cubic-bezier(.2,.7,.2,1) ease-out):

1 · --fd-rail 240 → 72 px — the grid column, so the main page reflows with it, no jump.
2 · Labels: opacity 1→0 + translateX(−10px); they finish fading by ~60% so nothing wraps as the column narrows. fd-icon-caption fades in over the last 40%.
3 · Wordmark: letters fade + slide left exactly as the labels do; the gold mark fades in at the same spot, scale .8→1. Both live inside the same 40 px .fd-brand button, so the hit target never moves.
4 · Rows go column-stacked (icon over caption), min-height 60px — the shipped 1279 icon-strip rule, now class-driven.

Reduced motion: @media (prefers-reduced-motion: reduce) → duration 0, state swaps instantly. Remembered per person in localStorage; default expanded.
