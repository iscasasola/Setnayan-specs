Event Details — set up by stage, one record, edited on the page

One home per fact. Event Details is the event's one record. A stage is a filter over that record, never a second home. Every row opens the same field the Maker opens on that part of the page; the page shows the change at once, and guests see it at Apply. Phone: full-width page, slim bars, one sheet. Desktop: the record beside the live page. No script — tap the pills.

1 · Which stage do you want ready? rule moved

Opens once, right after the event is created (the shipped "Finish your Event Hub"). Each stage's line counts only the facts that stage shows. Save the Date is first because guests see it first; Post Event fills itself from the day. Pick a stage and the next two screens change.

11 · An element's motion — effects combine; one vocabulary for Theme → Scene → Element new · combine · Grow · Shrink · corners · Blur rule · one dropdown, a checklist inside

Today an element's In is Rise · Fade · None (one at a time, no direction, no size); a scene's In has directions (below · above · left · right) but no size. One vocabulary for both: In ▾ is one dropdown with a checklist — Fade · Move · Grow / Shrink (one or the other) · Blur in — ticked together; From ▾ appears only when Move is ticked (below · above · left · right · four corners); Out ▾ the same set reversed, plus Settle back / Stay put. The label sums the pick. Tick and untick: the names replay on the page. Reduced motion → still.
