Event Details — set up by stage, one record, edited on the page

One home per fact. Event Details is the event's one record. A stage is a filter over that record, never a second home. Every row opens the same field the Maker opens on that part of the page; the page shows the change at once, and guests see it at Apply. Phone: full-width page, slim bars, one half-height sheet (drag up for more · hold Peek to see the whole scene). Desktop: the record beside the live page, the same rows in the same order. One thing open at a time — a dropdown, a fold or a menu closes the others. Undo beside Apply. See as ▾ on every preview. Revised 4 Oct after the owner's "yes to all". No script — tap the pills.

1 · Which stage do you want ready? rule moved

Opens once, right after the event is created (the shipped "Finish your Event Hub"). Each stage's line counts only the facts that stage shows. Save the Date is first because guests see it first; Post Event fills itself from the day. Pick a stage and the next two screens change.
