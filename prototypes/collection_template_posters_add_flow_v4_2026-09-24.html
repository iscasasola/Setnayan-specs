What this is

  • The collection-card template with poster covers. Each card is the event’s own poster in the public profile’s language (3:4, moon · wine-capiz · playbill · photo), filling the shape; the private glass strip over its foot carries the one attention item and the days left. Unknown is never a zero.
  • Sorted soonest first, undated last. Ten per page; the dashed tile only while the page has room; the empty state carries the invitation.
  • Adding one. The header (+), the dashed tile and the empty state open the real first step of create-event — “What kind of event are you planning?”, the type tiles in the live roster’s order (Wedding greyed: already planning), then the form as it ships (name · para kanino · when · where · guest count · budget feel). Only the Birthday tile is wired in this prototype. “Create” lands the new event at the tail as the fresh invitation-card poster, “Date to be set · Just getting started”, and the count, tile and pages update.
