Studio › Info — what they need to type, first

No title row, no preview: the page opens on the first input. What a couple must type is open on entry (the names, the opening line, a message, what to bring); the date and venue are one quiet line each (they are set when a venue is booked); everything optional sits below a break, folded, each saying in one line what it does for a guest. One row pattern for the whole Studio: label left with ⓘ, value or control right, one hairline. Per INTERACTION_RULES § 2: a value with 3 or more choices is ONE ▾ that opens its choices (Name style, Start from, Who can view); yes/no is a switch; free words are a field. Info has no sections and no two-way value, so it needs no segmented selector and gets none. Every row rides the draft and ✓ Apply — except the Event Hub address and access, which stay live and say so once.
