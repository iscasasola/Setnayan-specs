  • Workspace: tap a layer to pick it — a dashed frame with ↑ (upper-left, forward in the stack), ↓ (lower-left), 🔒 (upper-right) and ✕ (lower-right). Drag it to move. ▶ plays the picked layer’s Build in → Action → Build out; with nothing picked, the whole logo.
  • Layers carousel (where the event bar was): one card per layer, top of the stack first; the picked card is dark. Drag a card sideways to reorder. The last card ＋ Add opens one sheet: Text · Image · Frame · Ornament.
  • Tools row: Character (text only: words · font · size · spacing · colour · split into letters) · Style (looks as picture cards, colour, arrange, hide/lock/duplicate/delete) · Animate (Build in · Action · Build out). Help behind ⓘ. Every choice is a dropdown. Draft saves itself; ✓ Apply publishes.
