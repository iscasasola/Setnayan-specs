The Maker re-plan — the stages edit everything; Details slims; RSVP is a stage; Prints is a tab

Drawn on the approved Maker (2026-09-29 blueprint) and the approved Details page (2026-09-28): same bar, navigator, canvas and right panel. Only what the owner changed on 2026-09-30 is new. 1–7 · On every stage, the stage edits everything

Tap any scene, row or element → the right panel shows Preset ▾ (five, derived from the event’s info) · for text Wording ▾ or type right on the page · Format ▾ for dates and times · Frame ▾ for the logo · Hide · Style (the one font dropdown · colour · size · motion) · for a shared piece the hero-sharing bar. Rich pieces add “More … ›” which opens the full tool in the same panel with ‹ Back. A thin Opening strip above every stage’s first screen carries the opening (veil · seal · envelope …), which plays before it and holds no content. Small ⓘ everywhere a control is not self-evident; a few are drawn open.
