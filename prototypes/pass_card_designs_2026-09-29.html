The pass they save — three designs

Owner, 2026-09-29: "make sure the file they save the QR Card with the information of the guest. so when they save multiple QR Codes, it is easy. this should be a 4:3 portrait digital image. which can also be added on the prints" — and "only accepted accounts get their images."

Today the Me tab already shows the pass as a card (couple · date · Guest / Table / Arrive / Bringing · one large code · Show this at the door). What changes: Save writes a portrait 3 : 4 image, 1080 × 1440 PNG, named after the guest, that carries the same facts as the card on screen — so four saved passes in a family's Photos are four different cards, not four identical squares. The same image is the Phone card (3 : 4 portrait) format on the print sheet.

Omit rule (already the law in lib/guest-pass.ts): a fact that does not exist is left off — never "Table TBA", never a placeholder time. Each design below shows one card with no table yet to prove the layout still balances. The code is always black on white, whatever the theme, so it scans.

A · Classic card

Closest to the Me pass today. Couple and date at the top, the guest's name above the code, the code centred and large, the facts in one tidy row beneath. Quiet enough to sit next to a printed invitation.

B · Ticket / boarding pass

A portrait ticket with a real perforation. Top half: whose wedding, when, and who this is for. Tear-off stub: the code with Table and Arrive set like a gate and a boarding time — the two things a door asks. The notches are transparent in the PNG, so it reads as a ticket even in Photos.

C · Photo-poster

The couple's cover photo (or their theme's colour band when there is no photo yet) fills the top third, with the guest's name set over it. The code lives in a white rounded tile below, with Table and Arrive tucked inside the tile. The one that looks most like their wedding, and the easiest to tell apart in a grid of many events.

Who gets one

Only guests the couple has accepted get an image. The Save button on Me stays put, but until the couple confirms them a Pending or declined guest sees this instead of a card:

How the file is named
Maria-Santos-pass-Indalecio-Claire-2026-12-18.png
Guest first, so a family sorting Downloads sees four names, not four copies. Spaces become hyphens; the date is the event date, not today.

Why 1080 × 1440
Exactly 3 : 4, fills a phone screen held up at the door, and prints clean at 90 × 120 mm (about 300 dpi). The code sits at 528 px on the saved image — well above what a door scanner needs.

Theme follows the Event Hub
Each design is drawn in the couple’s theme — Classic cream and Cyber Neon shown here; the other themes get the same treatment. The code tile is always white.

Free events carry the small Setnayan mark at the foot. Paid Event Hubs drop it.
