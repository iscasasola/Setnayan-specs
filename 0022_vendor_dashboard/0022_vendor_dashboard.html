COLLISION-TOLERANCE PERMISSION
Can the agent book over an existing schedule?
Default (off): No. An agent attempting to accept a booking on a date that already has another booking gets a "Date already taken" error. Owner / Admin must intervene.
With override permission (per-agent toggle): Yes. Agent can book on a "Blocked · taken" date — useful for studios with parallel-shooter capacity (e.g., Carlo + Liana can shoot two prenups in different cities the same day). When invoked, a notification fires to the Owner so collisions are visible.

How Sponsored Boost works · three rules at once.
