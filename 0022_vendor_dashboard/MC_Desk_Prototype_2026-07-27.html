What's real, and what isn't

Three of these shipped today. Two are proposals from your notes — they're drawn dashed and gold on the screen above, and nothing behind them is built yet.

Built · in this PR

On now

What you're on, the line to say, what's next and when. If the night is behind, it says so — "due 15 min ago", never a blank. The couple's note for the current moment sits right here.

Built · in this PR

The running script

The whole evening, top to bottom. Finished moments fade back, the live one is marked, and the parts inside a moment sit under their parent — same shape as the script the couple downloads, because it's compiled from the same source.

Built · in this PR

Announcements

The couple's own notes, pulled out of the program so a long evening can't bury them. Private moments show up here too — stamped Don't read aloud, never hidden, because a host who doesn't know about the surprise is the one who ruins it.

Proposed · not built

My notes

The host's own cues, written by them, pinned to a moment. "Groom's lola is at table 3 — greet her." Theirs alone; the couple never sees them. This is the one an emcee will ask for first, because every one of them already does it on paper.

Proposed · not built

Ask the couple

A question from the stage, into the thread the host and couple already share — so it lands where they're used to talking, and there's a record. Needs a decision: does the coordinator get a copy, given they're the one relaying on the night?

Decided · staying human

The coordinator relays

No inbox for the host. The coordinator hears it and tells them — which is what already happens on a floor, and it's why the guest list and the coordinator's messages stay closed to suppliers.

One thing worth settling: should a host's own notes survive to their next wedding — a personal library they build over a career — or start clean each time?
