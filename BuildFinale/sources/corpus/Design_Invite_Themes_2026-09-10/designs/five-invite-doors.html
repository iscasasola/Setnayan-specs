What never changes

  • The card and its one action. A light paper plate, radius 22, a 3px top edge, and exactly one action-coloured control per door. A theme owns what sits behind the card, never the card.
  • One background, from the first tap to the hub. Every Pro door sits on the couple's reveal background — events.std_background, whatever they chose for the save-the-date: a colour, a paper, one of ten scenes, or their own photo. The sample here is Setnayan's own Golden hour scene. Cale & Ice's real one is their uploaded prenup photo, which isn't used on this page because it's personal.
  • The couple's colour is ornament. It lights panes, dyes velvet, marks a label and strings the twine — never text, never the button. Use the bar above to change it, pale colours included; every board starts on Cale & Ice's real #C97B4B.
  • The arrival. Reveal · Name · Reply · Enter. Google and Apple sit at the top of Reply, before anything is typed, and the email is also the login.
  • The price. Event Hub Pro, read live from the catalog today: ₱3,500, one unlock. The standalone reveal SKU no longer exists — the Cinematic Reveal already comes only inside Event Hub Pro.

Yours to decide

  • Does Pro's "Button color" reach the invite? Event Hub Pro sells it, but the invite door's action colour is locked at #C24E25 and a test guards that. Every Pro theme is now built with the button as a token, so either answer is a one-line change.
  • Is the invite theme an eighth Pro item? The code and the Event Hub controller design both say Pro is "the seven". The themes either join as an eighth, or ride on Cinematic Reveal + Background color + Button color.
  • Two veils, two envelopes. Capiz and Galeriya chose the sheer veil; Velvet and Abaca chose the four-flap envelope. The church doors and both two-flap openings went unused. Each is only the theme's default — Cale & Ice already picked the veil, and a couple's own choice should win.
  • Galeriya's print costs the fold. By hanging the photo as a print and keeping every word off it, Galeriya solved the hardest legibility case in the set (8:1 over the veil). But on the Name door the Continue button now sits around 808px, below the 640 line every other door respects. Keep the print, shorten it, or move it to the Reply door only.
  • Which theme a couple gets first. Each theme is picked up from the feel chosen in onboarding (mood_feel_key), which the couple can override. Cale & Ice never picked one, so today they would get House.
