# S1 — what to read, and what to send back

**This is the ten minutes that settles about forty-five open items.** Almost everything our
notes call "built but switched off" is what the *code* falls back to when nothing is set —
which is not the same as a reading of what is actually live.

---

## ⚠ Before anything: do NOT paste keys

That page also holds passwords and API keys. **Send back only the lines whose value is
`true` / `false` / `on` / `off` / `1` / `0` — nothing else.**

If a value looks like a long random string, a password, or ends in `_KEY`, `_SECRET`,
`_TOKEN`, `_DSN` or `_URL` — **skip it.** I never need those, and I should not see them.

---

## The fastest path (about 2 minutes)

1. Go to **Vercel → your project → Settings → Environment Variables**.
2. Filter to **Production**.
3. Copy the rows whose value is `true` or `false` — **name and value only**.
4. Paste them back to me in one lump. Order does not matter, and it does not have to be tidy.

That is the whole job. **If a name below is simply not on the page, that is the answer** —
say "not listed" and I will read it as the code's default.
