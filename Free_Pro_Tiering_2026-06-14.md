# Free vs Pro — Customer Tiering Map (2026-06-14)

> **Structural input to the pricing reprocess** — feeds `Pricing_Collection_2026-06-14.md`.
> **AMOUNTS ARE NOT SET HERE.** This fixes only the free-vs-paid *lines*. All ₱ stay owner-to-set in the one holistic pass (prices remain provisional).
> **Owner directive 2026-06-14:** every core planning tool is **free + has a Pro**; experiences that are cheap to run get a **free funnel + Pro**; productions with real per-unit cost stay **paid**. The free seat-plan-stays-free lock is honored — Pro is *additive*, never a paywall on the core function.

## The deciding principle — **cost to run**
- **Cheap to run** (software + capped storage) → **FREE funnel + Pro.** Give it small; upsell scale/polish/automation/your-uploads.
- **Real per-unit cost** (a produced song, an edited film, an 8K LED design, a live multi-cam broadcast) → **PAID.** Can't be given away — each unit costs real money/effort.
- **Guardrail:** every FREE tier is **deliberately capped** (storage, guest count, templates, retention) so free stays cheap to run and the Pro gap is obvious. (Per owner: "the free website should not eat up too much space.")
