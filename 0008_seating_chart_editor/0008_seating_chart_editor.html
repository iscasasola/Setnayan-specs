Couple Dashboard · Seating Chart Editor

Designer note — Desktop owns layout authoring (palette → canvas, free-place stage / band / dancefloor / doors, role-tier ring overlay). Mobile is review & quick-edit (table cards → bottom sheets). Auto-fill walks role-tier rings outward from the stage; sweetheart and locked tables are excluded. Chairs are circles around each table — profile photo when available, otherwise initials with a name pop-up on selection. Tap a chair swaps that guest to another seat; tap a table body swaps the whole table to another spot. Long-press opens details. Long & serpentine tables rotate in 45° increments. Venue dimensions are optional — set them and the editor enforces walls / doors / dancefloor as bounds; leave them blank and arrangement is free-form. Alignment lock snaps to other tables' edges and centerlines. QR tokens are minted only at Publish — until then, the Print pack is blank.
