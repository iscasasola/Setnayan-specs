# Suno Workstream Complete V1 — Maximize the Monthly Budget

> **What this file is.** The complete Suno Premier generation queue for Setnayan V1. Sister file to `Music_Catalogue_Suno_Prompts_V1.md` (the V1 template music catalogue). This file covers EVERYTHING ELSE the platform needs in audio form — brand sonic identity, app notification sounds, render bumpers, Patiktok original tracks library, founding-vendor theme songs, the owner's wedding day-of theme, marketing/brand video scoring, and forward-looking V1.5 expansion template music.

> **Why one comprehensive file.** Suno Premier credits don't roll over — unused credits expire at month-end. The single most efficient use of the $30 subscription is one focused month where you blitz the full workstream. This file is organized for that sprint.

> **Sister file:**
> [`Music_Catalogue_Suno_Prompts_V1.md`](Music_Catalogue_Suno_Prompts_V1.md) — V1 template music (47 prompts, ~235 generations target)

> **Suno safety rule (locked):** prompts capture **architectural feel** (instrumentation, tempo, build, mood) — NEVER name artists, song titles, or specific copyrighted works. All output is owned outright by Setnayan under Suno Premier terms.

## How to run the Suno Sprint

Suggested 3-week schedule:

| Week | Sessions | Focus |
|---|---|---|
| W1 | 3 × 3-hr sessions | V1 template music catalogue (sister file) — get the renderable V1 catalog done first |
| W2 | 2 × 3-hr sessions | Brand audio (sonic logo, notifications, bumpers) · V1.5 expansion templates |
| W3 | 2 × 3-hr sessions | Patiktok library · Founding-vendor themes · Owner's wedding theme · Marketing tracks |

Total: 7 sessions × 3 hrs = 21 hours of focused work over 3 weeks. Realistic for one person; faster with a teammate splitting.

For each section below:
1. Open Suno Premier (suno.com)
2. Copy the prompt as written
3. Set **Instrumental: ON** unless the prompt explicitly says "wordless vocals" or "vocal-led"
4. Generate
5. Listen to both takes Suno returns
6. Keep 1 (best take) and rename per the locked filename pattern
7. Tag in the catalogue manifest

## Suno generation guidelines (apply to all categories)

1. **Always set "Instrumental: ON"** unless the prompt explicitly says "wordless vocals" or "vocal-led"
2. **Generate the listed take count** — Suno gives 2 takes per generation, so generation count × 2 = total takes you'll hear
3. **Listen to the FULL take** before keeping — Suno sometimes loses the arc near the end
4. **Reject filler** — per the locked no-filler rule, only keep takes that feel flagship-grade
5. **Tag immediately** — name kept files per the locked filename pattern so the catalogue manifest stays clean
6. **Don't over-iterate** — if a prompt's 3 generations don't produce a keeper, slightly tweak the prompt (add "warmer," "more space," "slower tempo") rather than burning more credits on the same prompt
