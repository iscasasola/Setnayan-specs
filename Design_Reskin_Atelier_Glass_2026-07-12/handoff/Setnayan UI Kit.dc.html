UI Kit · Public Website

A reskin kit for setnayan.com

Keep the site exactly as it performs — same structure, same video hero, same IA, same copy. This kit changes only the skin: typeface, color, buttons, form controls, cards, chips and motion. Everything here is spec'd as drop-in CSS tokens + annotated components so Claude Code can apply it component by component.

How to apply this

1
Drop in tokens
Paste the :root block into your global stylesheet. Everything downstream references these variables.
2
Swap the font
Load Hanken Grotesk, set it as the UI family. Leave layout, spacing and markup structure untouched.
3
Restyle by component
Match each component below to its live counterpart and apply the classes. Behavior/JS stays as-is.
Golden rule — frame only what's interactive. Buttons, inputs, tappable tiles and chips get a surface/border. Plain text, headings, stats and captions sit directly on the paper. This is the single biggest visual shift from the current build.
01 · Tokens

Design tokens

The whole reskin reduces to these variables. The current site's #FBFBFA paper stays almost identical — just warmed a hair — so the hero video and photography still sit right.

paste into :root

  /* paper & ink */
  --sn-paper:      #FBFAF7;
  --sn-surface:    #FFFFFF;
  --sn-hairline:   #EDE8DE;
  --sn-line:       #E1DCD1;
  --sn-ink-300:    #A09A8E;
  --sn-ink-500:    #6E6A62;
  --sn-ink-700:    #3A382F;
  --sn-ink-900:    #1B1A17;
  --sn-ink-black:  #17160F;
  /* gold accent */
  --sn-gold-100:   #F3ECDF;
  --sn-gold-300:   #CBA766;
  --sn-gold-500:   #A9834B;
  --sn-gold-700:   #8A6B39;
  /* semantic (warm-tuned) */
  --sn-success:    #5E7C52;
  --sn-warning:    #B77E2E;
  --sn-danger:     #A6483B;
  --sn-info:       #4E6C82;
  /* type */
  --sn-font: "Hanken Grotesk", system-ui, sans-serif;
  --sn-mono: "Space Mono", ui-monospace, monospace;
  /* radius */
  --sn-r-sm: 6px;  --sn-r-md: 10px;
  --sn-r-lg: 14px; --sn-r-pill: 999px;
  /* elevation (warm, never grey) */
  --sn-sh-sm: 0 1px 2px rgba(30,26,18,.06);
  --sn-sh-md: 0 20px 34px -22px rgba(30,26,18,.40);
  --sn-sh-lg: 0 40px 80px -50px rgba(30,26,18,.55);
  /* motion */
  --sn-ease: cubic-bezier(.2,.7,.2,1);
  --sn-dur:  .2s;
  /* glass (macOS vibrancy) */
  --sn-glass-bg:   rgba(255,255,255,.55);
  --sn-glass-line: rgba(255,255,255,.75);
  --sn-glass-blur: blur(18px) saturate(1.4);
}
