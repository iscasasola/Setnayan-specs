# Rules of Creating a Wax Seal Stamp — craft study → digital sim rules (2026-06-15)

> Reference for the **Wax Stamp Creation Experience** (couple mints their own seal). Studied from real wax-sealing craft guides so our physics sim follows real matter. Pairs with `0024_ADDENDUM_envelope_open_experience_2026-06-14.md` §3 + 0037 bespoke monogram.

## The one governing idea
Sealing wax is a **thermoplastic**: solid → liquid with heat (~160–180°F / 71–82°C), re-hardens as it cools. The entire craft is hitting **one viscosity window** — the moment the wax is *soft but no longer runny*.

## The real process (rules per step)

| # | Step | Physical rule | Failure if broken |
|---|---|---|---|
| 0 | **Material** | Wick / wickless / bead-in-spoon / glue-gun sticks. "Flexible" wax = + resin → bends, matte, mail-safe. Traditional = brittle, glossy. | Brittle wax cracks/shatters if flexed |
| 1 | **Melt** | Melt slowly, stir for even melt; keep below boiling. | **Overheat = bubbles, discolour, separation, thin/shapeless wax** (the #1 enemy) |
| 2 | **Pour the puddle** | Pour when runny-but-not-boiling, a ~0.75–1" circle. Liquid wax **self-levels into a round bead**; size = amount poured. | Too little = thin; too much = won't set in time |
| 3 | **Cool ~10s — THE window** | Wait until surface is **"soft but no longer runny."** | **Too soon (too liquid) = smear / flow / bubbles / sticks.** Too late (hard) = shallow, won't take |
| 4 | **Prep stamp (anti-stick)** | **Chill** stamp on ice and/or **moisten** (breath / damp sponge); cool stamp also sets wax faster. | Warm/dry stamp = wax sticks in the engraving |
| 5 | **Press straight down, firmly** | Vertical press; **never twist/turn.** Displaces wax → field **debosses**, design **embosses up**, edge **bulges**. (Swirl only to de-bubble.) | Twist = smeared/torn detail |
| 6 | **Hold + release clean** | Hold 30s+ to set; **lift straight up or rock gently**, never twist; don't lift early. | Early/twist lift = smear/tear; warm stamp sticks |

## The 3-zone consistency window (the heart of it)
1. **Too liquid (hot):** impression **flows back / smears**, traps bubbles, sticks. → won't hold.
2. **Soft-set (the sweet spot):** takes a **crisp, deep, clean** press. ← target.
3. **Too hard (cold):** **shallow / incomplete** print, design won't fully take.

## Mapping to our digital sim — honor / fix
- ✅ Already true: pour = self-leveling liquid; hotter = more flow; cooled = holds; displaced-wax bulge; deboss field + emboss logo.
- 🔧 **Add the THREE-zone outcome** (we only had 2): too-liquid → smear/flow-back; **soft-set → crisp** (the reward window); **too-hard → shallow/partial** (press barely registers). Surface this on the consistency meter (a highlighted "ready" band, hot above / firm below).
- 🔧 **Timing feel:** pour→press window ≈ 10–20s; meter should rest in "ready" long enough to act, then drift to "firm."
- 🔧 **No-twist release:** press is a straight down/up; if "twist"/drag on release, smear the detail (or simply disallow). Lifting while still molten = smear.
- 🔧 **Overheat → bubbles:** pouring too much too fast (very hot) can seed tiny surface bubbles + a softer, less-defined press.
- 🟡 Optional craft flavour: a "chill / breathe on the stamp" beat before pressing (anti-stick), and a **finish** choice — glossy (traditional) vs matte (flexible). Our default matte ≈ flexible/modern.
- ⚙️ Result is unique per pour (matter governs) → mints the couple's one-of-a-kind seal; recolours to the moodboard deep-accent.
